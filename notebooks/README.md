# Downstream Analysis & Topic Modeling

This directory contains the exploratory data analysis (EDA) and neural topic modeling workflows that accompany the survey paper:

> **"A Survey on Adversarial Multi-Agent Deep Reinforcement Learning"**  
> *ACM Computing Surveys (CSUR)*, Manuscript ID: `CSUR-2025-1595`.

---

## Directory Contents

| File | Description |
| :--- | :--- |
| `eda.ipynb` | Exploratory data analysis on filtered literature results: publication timeline distributions, publisher source proportions, and LLM relevance ratios. |
| `bertopic.ipynb` | End-to-end neural topic modeling pipeline using BERTopic (Sentence-BERT embeddings, UMAP dimensionality reduction, HDBSCAN clustering, and KeyBERT MMR representation). |
| `papers_content.csv` | Preprocessed corpus dataset containing extracted titles, abstracts, and metadata. |
| `papers_topics.csv` | Topic assignments and probability distributions generated by the BERTopic model. |

---

## Environment Setup

To keep the core scraper lightweight, analytical dependencies are maintained in `requirements-analysis.txt` at the repository root.

## Reproducing the Analysis

### 1. Exploratory Data Analysis (`eda.ipynb`)
- **Input:** `./results/filtred_papers.xlsx` (or `notebooks/papers_content.csv`).
- **Analyses Performed:**
  - Distribution of papers across publication years (2018–2024).
  - Source representation across academic venues and digital libraries (IEEE, ACM, Springer, arXiv, NeurIPS, etc.).
  - Relevance filtering efficacy and acceptance ratio.

### 2. Neural Topic Modeling (`bertopic.ipynb`)
- **Input:** `notebooks/papers_content.csv`.
- **Pipeline:**
  1. **Preprocessing:** Tokenization, stopword removal, character/token length profiling.
  2. **Embeddings:** Dense semantic vector representations via `sentence-transformers`.
  3. **Dimensionality Reduction:** Non-linear manifold learning with `umap-learn`.
  4. **Clustering:** Density-based hierarchical clustering with `hdbscan`.
  5. **Topic Representation:** c-TF-IDF and KeyBERT with Maximal Marginal Relevance (MMR).
- **Output:** Categorization into 4 survey pillars (*Attacks*, *Defenses*, *Communication*, *Applications*) and export to `papers_topics.csv`.
